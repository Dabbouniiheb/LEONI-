# Exigences du rapport final

## Livrables obligatoires dans `output/`

- `rapport_stage_final.md`
- `rapport_stage_final.html`
- `rapport_stage_final.docx`
- `rapport_stage_final.pdf`
- `rapport_qa_final.md`
- dossier `assets/` contenant les figures réellement utilisées

## Cible

- langue : français académique ;
- style : clair, naturel, précis et cohérent ;
- pagination finale : **64 pages** ;
- format : A4 ;
- table des matières actualisable ;
- titres hiérarchisés ;
- numérotation cohérente des figures et tableaux ;
- aucune information fictive ;
- aucune donnée personnelle visible dans les captures.

## Structure attendue

1. Page de garde
2. Dédicace
3. Remerciements
4. Résumé et mots-clés
5. Abstract et keywords
6. Table des matières
7. Liste des figures
8. Liste des tableaux
9. Liste des abréviations
10. Introduction générale
11. Chapitre 1 - Présentation de l'organisme et cadre du stage
12. Chapitre 2 - Analyse et conception
13. Chapitre 3 - Réalisation
14. Chapitre 4 - Tests et validation
15. Conclusion générale
16. Perspectives
17. Références
18. Annexes utiles

## Règles de rédaction

- Employer le titre officiel fourni.
- Décrire LEONI avec prudence et sans inventer de données institutionnelles.
- Présenter `Material Master Data Management` comme périmètre métier.
- Expliquer clairement le passage d'Excel à une plateforme centralisée.
- Distinguer les besoins initiaux, les fonctions réalisées et les perspectives.
- Décrire les deux rôles et leurs permissions.
- Détailler les règles A/B et la fenêtre du 25.
- Décrire l'architecture sans prétendre que toutes les couches sont uniformes.
- Expliquer les transactions, contraintes et mécanismes de sécurité.
- Remplacer les anciennes données de tests par les résultats du 17 juillet 2026.
- Utiliser les diagrammes PlantUML locaux.
- Utiliser uniquement les captures réellement fournies.
- Ne pas allonger artificiellement le texte avec des répétitions pour atteindre 64 pages.

## Ajustement à 64 pages

Après génération :

1. rendre le DOCX/PDF ;
2. compter les pages ;
3. ajuster les dimensions des figures, les espacements et les annexes utiles ;
4. conserver une mise en page lisible ;
5. viser exactement 64 pages sans masquer de contenu ni créer de pages vides inutiles.
