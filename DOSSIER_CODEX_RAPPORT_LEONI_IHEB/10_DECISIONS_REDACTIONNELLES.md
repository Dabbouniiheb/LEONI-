## À supprimer du rapport

- adresse ;
- description détaillée et organigramme du département ;
- fonction de l'encadrant professionnel ;
- encadrant académique ;
- modalités de présence ;
- confidentialité et autorisations non documentées ;
- champs vides correspondant à ces éléments ;
- demande de noms supplémentaires pour les remerciements ;
- données institutionnelles non vérifiées ;
- mention d'une mise en production ;
- compte ou mot de passe de démonstration.
